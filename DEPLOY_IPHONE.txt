AI Քարտուղար — бесплатная публикация через GitHub Pages (iPhone)

1. В Safari откройте https://github.com и создайте бесплатную учётную запись (если её нет).
2. Нажмите + → New repository. Название: ai-qartughar-demo. Выберите Public → Create repository.
3. В репозитории выберите Add file → Upload files. Загрузите содержимое этого ZIP-архива (index.html, voice_demo.html, manifest.webmanifest, sw.js, .nojekyll). Не загружайте сам ZIP как единственный файл.
4. Нажмите Commit changes.
5. Откройте Settings → Pages → Build and deployment → Deploy from a branch. Выберите main и / (root) → Save.
6. Подождите публикации и откройте ссылку, показанную в разделе Pages (обычно https://ВАШ-ЛОГИН.github.io/ai-qartughar-demo/).
7. В Safari: Поделиться → На экран «Домой».

Важно: репозиторий Public, поэтому исходный код виден всем. НЕ добавляйте в него телефоны, имена клиентов, пароли, API-ключи или реальные заявки. Демо хранит введённые заказы только в браузере конкретного устройства; синхронизации между устройствами нет. Не используйте демо для конфиденциальных клиентских данных.

Голосовой ввод и армянская озвучка зависят от возможностей Safari/iOS и могут быть недоступны. Это не подключение к Ucom и не действующий AI-телефонный оператор.
